# ORBIT

A personal browser start page with glowing bookmark orbits and a layered starfield.

## Publish with GitHub Pages

Upload the contents of this folder to the repository root, keeping the folders intact.
Open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
No build step, ChatGPT account, server, or API key is needed to open the page.

## Chrome on Windows and macOS

For startup: Settings → On startup → Open a specific page → paste the Pages URL.
For every new tab: disable Infinity, install a new-tab URL redirect extension, and set the Pages URL.

## Personal data

- The five default shortcuts are public: Amap, Baidu Maps, Notion, GPT and Bilibili.
- Added/edited bookmarks, weather city and motion preference are stored in this browser's localStorage.
- Visitors have separate local settings. Their edits do not change yours or the repository.
- Settings do not sync between devices or between the former site address and the Pages address.
- Weather is requested from Open-Meteo. Unbundled website favicons are requested from Google's favicon service.
- Outlook is currently a link only. Microsoft sign-in and unread counts are not connected yet.
- Never commit mailbox tokens, passwords or client secrets to this repository.

Three.js and bundled favicons run directly in the browser. Original third-party marks remain the property of their owners; see icons/SOURCE.txt and vendor/THREE-LICENSE.txt.
